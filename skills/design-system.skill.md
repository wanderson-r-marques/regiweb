# Design System - Regiweb

## Cores
- `--bg-primary`: `#0a0a0a`
- `--bg-card`: `#202024`
- `--color-brand`: `#8257e6`
- `--color-green`: `#00b37e`
- `--gradient-brand`: `linear-gradient(135deg, #8257e6 0%, #00b37e 100%)`

## Tipografia
- **Headings**: `Nunito` ou `Plus Jakarta Sans`
  - Peso: `800`
  - Tracking (Letter-spacing): `-0.03em`
- **Body**: Sugere-se `Inter` ou `Roboto` para legibilidade em parágrafos.

## Elementos de UI
- **Navbar**: Deve possuir um efeito de `backdrop-blur` sutil.
- **Hero Section**:
  - Headlines em gradiente utilizando o `--gradient-brand`.
  - Elementos flutuantes.
- **Glows**: Utilizar variações da `--color-brand` com opacidade reduzida para criar efeitos de brilho em backgrounds e bordas.
